Deadline Board

Submission dates for the venues this group actually publishes in, read from each conference’s own dates page rather than typed out by hand.

Where this comes from. Each conference’s dates page on conf.researchr.org, fetched by scripts/deadlines.py and generated into data/deadlines.yaml. Add one with python scripts/deadlines.py add <slug>. Dates are shown exactly as the conference publishes them; where a conference states a timezone it is given beside the row, and AoE means anywhere-on-earth. Always check the conference site before relying on a date.
